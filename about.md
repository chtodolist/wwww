# Frame Window Counter

Adds an **FWC** button to the top right of the pause menu. Load a `.gdr2` macro and the mod measures how many frames each click can be moved earlier or later before the attempt dies, then counts the clicks that fall into 1-, 2-, 3-, 4- and 5+-frame windows.

- Per-click window list and colour-coded click timeline
- CSV and JSON export
- Works on classic (non-platformer) macros

Put macros in the mod's `macros` save folder (use the **Folder** button) or set an extra folder in the mod settings.
